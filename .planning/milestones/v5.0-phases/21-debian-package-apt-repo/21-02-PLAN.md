  <action>
1. `scripts/make-apt-key.sh`: exit 0 early if the fingerprint file exists
   (idempotent); else `gpg --batch --passphrase '' --quick-gen-key 'Pushframe
   APT Repository <deploy@pushframe>' rsa2048 sign 0` with
   `%no-protection`-style batch params; export secret to
   `~/.config/pushframe-apt-key/signing-key.asc` (0600, gitignored path);
   write the fingerprint to that dir; print it.
2. `scripts/publish-apt-repo.sh [--dry-run]`:
   a. Require the deb (build if missing) + the signing key (call make-apt-key).
   b. Assemble `build/apt-repo/`: copy deb into
      `pool/main/p/pushframe/pushframe_<v>_amd64.deb`; run
      `dpkg-scanpackages --multiversion pool/ /dev/null > dists/stable/main/binary-amd64/Packages`
      (with the apt `Filename:` lines pointing at the pool path);
      hand-build `dists/stable/Release` (Origin: pushframe, Label: pushframe,
      Suite: stable, Codename: stable, Architectures: amd64, Components: main,
      Date (RFC2822), Description; then `sha256sum` sections for Packages and
      the per-file hashes in the standard layout).
   c. Sign: `gpg --clearsign --local-user <fp> -o InRelease Release` and
      `gpg -abs -o Release.gpg Release`; export the public key to
      `dists/pushframe.asc`.
   d. `--dry-run`: stop here, print the tree + the exact git commands it WOULD run.
   e. Publish: orphan-commit the tree to `gh-pages` and `git push --force origin gh-pages`
      (worktree technique: `git worktree add` on a temp orphan branch, copy tree,
      commit, push, clean up). Print the Pages URL and remind that Pages must be
      enabled once (Settings → Pages → gh-pages, root).
  </action>
  <acceptance_criteria>
    - make-apt-key is idempotent (second run prints the same fingerprint, no new key)
    - publish --dry-run leaves a complete tree: InRelease + Release + Release.gpg + pushframe.asc + Packages + pool deb
    - `gpg --verify InRelease` (with the exported pub key in a temp keyring) succeeds
    - Nothing secret is written inside the repo (key dir gitignored)
  </acceptance_criteria>
  <verify>
